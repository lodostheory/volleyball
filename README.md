# VOLLEYBALL MANIA

배구 **경기 영상 분석**과 2D 아케이드 **배구 게임**을 담은 웹앱입니다.

- 설치가 필요 없는 웹앱(PWA) — `index.html`(탭 화면)이 `analysis.html`(경기 분석)과 `game.html`(배구 게임)을 불러와 동작, 홈 화면에 추가하면 전체 화면 앱처럼 실행
- 화면 위 탭으로 **📹 경기 분석** · **🎮 게임** 을 오감 (아래 「경기 영상 분석 탭」·「배구 게임 탭」 참고). 처음 열면 경기 분석
- 아이폰처럼 세로로 긴 화면과 갤럭시 폴드 펼침 화면, PC 모두에 맞춰 크기가 조정됨. 한 번 열면 오프라인에서도 실행
- 예전의 9인제 **수비 포메이션 시뮬레이터(포메이션 탭)는 2026-11-19 에 삭제**함. 코드는 git 기록(커밋 `f43ac3d` 까지의 `index.html`)에 남아 있음

## 휴대폰에서 실행하기 (GitHub Pages)

1. GitHub Pages 는 `gh-pages` 브랜치로 게시됨. `main` 에 올리면 `.github/workflows/pages.yml` 이 자동으로 `gh-pages` 에 반영
2. 휴대폰 브라우저에서 `https://lodostheory.github.io/volleyball/` 접속 (반영까지 1~2분)
3. 아이폰: Safari 공유 버튼 → **홈 화면에 추가** / 갤럭시: Chrome 메뉴 → **홈 화면에 추가**

## 서버 (Cloudflare Worker)

- 서버 코드는 `worker/` (Cloudflare Workers + KV), 주소는 `https://vollyball-mania.lodostheory.workers.dev`
- 경기 분석 탭의 경기 기록 저장: `GET /matches`, `GET·PUT·DELETE /matches/:name`. 저장한 내용이 다른 기기에 보이기까지 최대 1분쯤 걸릴 수 있음
- `/teams` 는 예전 포메이션 탭의 팀 저장용입니다. 화면은 없어졌지만 서버 기능과 저장된 팀 데이터는 그대로 남아 있음
- 배포: `worker` 폴더에서 `npx wrangler deploy` (Cloudflare 로그인 필요)

## 경기 영상 분석 탭

- **📹 경기 분석** 탭(`analysis.html`, 바로 열기 `https://lodostheory.github.io/volleyball/#analysis`)에서 유튜브 경기 영상을 보면서 득점마다 기록
- 영상 자동 인식은 하지 않음(유튜브가 영상 읽기를 막음). 전력분석 프로그램(DataVolley · VolleyStation)처럼 **영상을 보면서 코드로 동작을 하나씩 기록**하는 방식
- **코드 입력**: `[팀] 등번호 동작 [평가] [구역]` — 팀은 없음 = 우리, `a` = 상대 / 동작 `S` 서브 · `R` 리시브 · `E` 토스 · `A` 공격 · `B` 블로킹 · `D` 디그 · `F` 프리볼 / 평가 `#` 완벽·득점 · `+` 좋음 · `!` 보통 · `-` 나쁨 · `/` 차단당함·넘어감 · `=` 범실
  - 예: `7S+ a12R- a5E a9A#46` (구역 숫자를 붙이면 보드에 화살표 자동). 한글 입력 상태로 쳐도 됨(ㄴ → S)
  - 각 동작에 영상 시각이 함께 저장됨(입력 지연을 생각해 기본 2초 앞으로 보정)
  - `S#` `A#` `B#` 은 그 팀 득점, `=` 는 상대 득점, `A/` 는 블로킹 팀 득점 → **점수가 자동으로 오르고 다음 랠리로**. 득점 직후의 짝 동작(`S#↔R=`, `A#↔D=`·`B=`, `A/↔B#`)은 방금 랠리에 붙음. `p` / `ap` 는 동작 없이 점수만
  - 키: `Enter`·`Space` 입력, 빈 칸에서 `Space` 영상 재생/정지, `[` `]` 2초 이동, `{` `}` 10초, `\` 느리게, 빈 칸에서 `Backspace` 되돌리기
- **터치 패드**: 팀 → 번호 → 동작 → 평가를 누르면 입력. 서브 다음엔 상대 리시브, 리시브 다음엔 토스처럼 다음 팀·동작을 미리 골라 둠
- 보드: 상대 코트(위)와 우리 코트(아래) 전체, 양 팀 9명씩 18명, 구역 번호 표시. 선수를 끌어 위치 이동, 선수를 탭한 뒤 코트를 탭하면 공격 화살표, 서브·공격을 넣은 직후 코트를 탭하면 그 동작의 방향 기록
- 랠리가 끝나면 그 순간의 18명 위치와 동작들이 한 랠리로 저장. 기록 목록의 줄을 누르면 그 랠리를 다시 보드에 띄우고 영상도 그 시각으로 이동하며, 고치거나 지울 수 있음
- 점수판: 팀 이름 입력, 세트 점수(15/21/25점, 2점 차), 3세트 2선승. 경기가 끝나면 기록이 잠김
- **자동 통계**(선수별 · 팀 합계): 득점, 서브(시도 · 에이스 · 범실 · 효율), 리시브(시도 · 정확 · 완벽 · 범실), 공격(시도 · 득점 · 범실 · 차단 · 성공률 · 효율 · 점유율), 블로킹 득점, 디그(시도 · 성공), 토스 횟수, 팀 사이드아웃 · 브레이크 비율과 득점 구성
- **장면 모아 보기**: 통계의 밑줄 숫자를 누르면 그 동작들만 모아 영상 클립으로 이어 재생(앞 · 뒤 초 조절)하고, 보드에 방향을 한꺼번에 표시
- **⬇ CSV**: 모든 동작 기록을 엑셀에서 열 수 있는 CSV 파일로 받기
- **🤖 AI 영상 인식** (PC 전용): `analyzer\run_server.bat` 으로 PC 에 분석 서버를 켜고 `http://127.0.0.1:8765/app/#analysis` 로 열면(브라우저 권한 없이 바로 연결), 유튜브 영상을 받아 YOLO 포즈 · ByteTrack 추적 · 공 궤적으로 터치 장면 후보(시각 · 코트 쪽 · 동작 추정 · 선수 위치)를 찾아 줌. 후보를 하나씩 영상으로 보며 번호 · 평가만 눌러 확정하고, 엑셀 리포트도 받을 수 있음 → 자세한 내용은 [`analyzer/README.md`](analyzer/README.md)
- **☁ 서버 저장**: 경기 이름과 비밀번호로 서버에 저장(보기는 누구나, 수정 · 삭제는 비밀번호). **📂 경기 목록** 에서 불러오기. 저장 전 기록은 그 기기에 자동 보관
- 서버 API: `GET /matches`, `GET·PUT·DELETE /matches/:name` (위 「서버」 참고)

## 배구 게임 탭

- **🎮 게임** 탭에서 2D 아케이드 배구 게임 「THUNDER VOLLEY」(6인제, 1920×1080 화면)를 할 수 있음. 게임 파일은 `game.html` 이며 탭은 이를 iframe 으로 불러옴
- 바로 열기: `https://lodostheory.github.io/volleyball/#game` (탭 포함) 또는 `https://lodostheory.github.io/volleyball/game.html` (게임만)
- 모드: 1P vs CPU · 2P 대전(키보드 하나로 둘이) · CPU vs CPU, CPU 난이도 EASY/NORMAL/HARD, 15점 3세트 2선승
- 키보드: ←→ 또는 A/D 이동, Z · Space · F = HIT(서브 · 리시브 · 토스 · 스파이크), X · G = JUMP, P 일시정지, ESC 타이틀
  - 2P 대전: 1P는 A/D · F(HIT) · G(JUMP), 2P는 ←/→ · K(HIT) · L(JUMP)
  - 점프 중 HIT = 스파이크 (전진키: 깊게 / ↓: 급각도 / ↑: 페인트), 토스 때 전진키 = 속공 / 후진키 = 오픈, 네트 앞 점프 = 블로킹
- 휴대폰: 왼쪽 패드로 이동, 오른쪽 **HIT** · **JUMP** 버튼. 메뉴는 항목을 탭해서 변경. 가로로 돌리면 더 크게 보이고, 오른쪽 위 버튼으로 전체 화면(안드로이드 · PC)
- 경기 분석 탭으로 옮기거나 앱을 내리면 게임은 자동으로 일시정지

# VOLLYBALL MANIA

9인제 배구 감독용 **수비 포메이션 시뮬레이터**. 상대 공격 루트(레프트 · 라이트 · A속공 · B속공 · BA속공 · 시간차)를 고르면
우리 팀 9명이 기본 위치에서 지정한 수비 위치로 이동하는 모습을 애니메이션으로 보여 줍니다.

- 설치가 필요 없는 웹앱(PWA) — `index.html`(포메이션)과 `game.html`(배구 게임)로 동작, 홈 화면에 추가하면 전체 화면 앱처럼 실행
- 화면 위 탭으로 **🏐 포메이션** · **📹 경기 분석** · **🎮 게임** 을 오감 (아래 「경기 영상 분석 탭」·「배구 게임 탭」 참고)
- 아이폰 Pro Max 같은 세로로 긴 화면과 갤럭시 폴드 펼침 화면 모두에 맞춰 크기가 조정됨(가로로 넓은 화면에서는 코트 왼쪽·버튼 오른쪽 배치)
- **위치 편집** → 선수(S·A·BA / L·M·R / LB·MB·RB), 상대 세터·공격수, 공격 목표 지점을 손가락으로 끌어 옮긴 뒤 **저장**
- 저장 내용은 기기 브라우저(localStorage)에 보관됨. 한 번 열면 오프라인에서도 실행

## 휴대폰에서 실행하기 (GitHub Pages)

1. GitHub Pages 는 `gh-pages` 브랜치로 게시됨. `main` 에 올리면 `.github/workflows/pages.yml` 이 자동으로 `gh-pages` 에 반영
2. 휴대폰 브라우저에서 `https://lodostheory.github.io/vollyball/` 접속 (반영까지 1~2분)
3. 아이폰: Safari 공유 버튼 → **홈 화면에 추가** / 갤럭시: Chrome 메뉴 → **홈 화면에 추가**

## 화면 보는 법

- 화면 위쪽이 상대 코트, 아래쪽이 우리 코트. 상대는 우리를 마주 보므로 **상대 레프트 공격은 화면 오른쪽**에서 들어옵니다.
- 우리 선수: 전위 S·A·BA, 중위 L·M·R, 후위 LB·MB·RB (선수마다 색이 다름). 상대 세터는 `세`로 표시
- 우리 코트는 옅은 회색선으로 3×3 구역으로 나뉘며, 번호는 네트 쪽 왼쪽부터 줄 단위로 1~9
- 점선 원과 점선 = 기본 위치와 이동 경로, 빨간 화살표 3개(①②③) = 공격 코스. 공도 세 코스로 동시에 날아가며 세 목표 지점 모두 편집 모드에서 옮길 수 있음
- 패턴 버튼의 초록 점 = 초기값에서 직접 수정한 패턴

## 팀 저장 (Cloudflare 서버)

- 화면 위 **팀 선택** 버튼으로 팀을 추가·선택. 팀을 선택하면 그 팀 이름으로 서버에 저장된 위치가 표시됨
- 팀을 선택한 상태에서 위치 편집 후 **저장**하면 서버에 저장됨. 저장할 때는 팀을 만들 때 정한 비밀번호가 필요(기기에서 한 번 입력하면 기억). 보는 것은 누구나 가능
- 팀을 선택한 뒤 **팀 선택** 화면에서 그 팀의 이름 변경·삭제 가능(비밀번호 필요)
- 팀을 고르지 않으면(내 기기) 이전처럼 그 기기에만 저장
- 서버 코드는 `worker/` (Cloudflare Workers + KV), 주소는 `https://vollyball-mania.lodostheory.workers.dev`. `index.html` 의 `API_URL` 에 지정되어 있으며, 비우면 팀 버튼이 숨겨짐
- 저장한 내용이 다른 기기에 보이기까지 최대 1분쯤 걸릴 수 있음

## 경기 영상 분석 탭

- **📹 경기 분석** 탭(`analysis.html`, 바로 열기 `https://lodostheory.github.io/vollyball/#analysis`)에서 유튜브 경기 영상을 보면서 득점마다 기록
- 영상 자동 인식은 하지 않음(유튜브가 영상 읽기를 막음). 득점이 나면 영상을 멈추고 보드를 정리한 뒤 득점 버튼을 누르는 방식
- 보드: 상대 코트(위)와 우리 코트(아래) 전체, 양 팀 9명씩 18명. 선수를 끌어 위치 이동, 선수를 탭한 뒤 코트를 탭하면 공격 화살표 (결과: 득점 · 범실 · 차단됨 · 연결)
- 득점 버튼을 누르면 그 순간의 18명 위치와 공격이 한 랠리로 저장. 기록 목록의 줄을 누르면 그 랠리를 다시 보드에 띄우고 영상도 그 시각으로 이동하며, 고치거나 지울 수 있음
- 점수판: 팀 이름 입력, 세트 점수(15/21/25점, 2점 차), 3세트 2선승. 경기가 끝나면 기록이 잠김
- 선수별 기록: 득점(공격 · 블로킹 · 서브), 공격 성공률(공격 득점 ÷ 공격 시도), 공격 점유율(선수 시도 ÷ 팀 시도)
- **☁ 서버 저장**: 경기 이름과 비밀번호로 서버에 저장(보기는 누구나, 수정 · 삭제는 비밀번호). **📂 경기 목록** 에서 불러오기. 저장 전 기록은 그 기기에 자동 보관
- 서버 API: `GET /matches`, `GET·PUT·DELETE /matches/:name` (팀 저장과 같은 Worker · KV)

## 배구 게임 탭

- **🎮 게임** 탭에서 2D 아케이드 배구 게임 「THUNDER VOLLEY」(6인제, 1920×1080 화면)를 할 수 있음. 게임 파일은 `game.html` 이며 탭은 이를 iframe 으로 불러옴
- 바로 열기: `https://lodostheory.github.io/vollyball/#game` (탭 포함) 또는 `https://lodostheory.github.io/vollyball/game.html` (게임만)
- 모드: 1P vs CPU · 2P 대전(키보드 하나로 둘이) · CPU vs CPU, CPU 난이도 EASY/NORMAL/HARD, 15점 3세트 2선승
- 키보드: ←→ 또는 A/D 이동, Z · Space · F = HIT(서브 · 리시브 · 토스 · 스파이크), X · G = JUMP, P 일시정지, ESC 타이틀
  - 2P 대전: 1P는 A/D · F(HIT) · G(JUMP), 2P는 ←/→ · K(HIT) · L(JUMP)
  - 점프 중 HIT = 스파이크 (전진키: 깊게 / ↓: 급각도 / ↑: 페인트), 토스 때 전진키 = 속공 / 후진키 = 오픈, 네트 앞 점프 = 블로킹
- 휴대폰: 왼쪽 패드로 이동, 오른쪽 **HIT** · **JUMP** 버튼. 메뉴는 항목을 탭해서 변경. 가로로 돌리면 더 크게 보이고, 오른쪽 위 버튼으로 전체 화면(안드로이드 · PC)
- 포메이션 탭으로 옮기거나 앱을 내리면 게임은 자동으로 일시정지

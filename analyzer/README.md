# 배구 영상 인식 서버 (analyzer)

VOLLEYBALL MANIA 「📹 경기 분석」 탭의 **🤖 AI 영상 인식** 이 쓰는 PC용 분석 서버입니다.
유튜브(또는 체육관 고정 카메라) 경기 영상에서 선수와 공을 찾아 **터치 장면 후보**(시각 · 코트 쪽 · 동작 추정 · 선수 트랙 · 그 순간 모든 선수 위치)를 뽑고, 엑셀 리포트도 만듭니다.
분석 탭에서는 이 후보를 하나씩 영상으로 확인하며 선수 번호와 평가만 눌러 기록을 확정합니다.

```
유튜브 주소 ─ yt-dlp ─▶ 영상 파일 ─▶ ① 코트 모서리 4점 → 원근 변환(m), 코트 밖 가리기
                                    ② YOLO11 포즈(17관절) + ByteTrack 추적 (선수마다 트랙 번호)
                                    ③ 공 탐지(COCO sports ball 또는 배구공 전용 가중치) + 궤적
                                    ④ 공 궤적이 꺾이는 순간 = 터치 → 가장 가까운 선수
                                       자세(점프·손 위치·낮은 자세)+코트 위치(엔드라인·네트)+랠리 흐름으로
                                       서브 S · 리시브 R · 토스 E · 공격 A · 블로킹 B · 디그 D 추정
                                    ⑤ 이벤트 JSON · 엑셀(선수별 동작 요약, 전체 로그) 저장
```

## 실행 (Windows)

1. [Python 3.12](https://www.python.org/downloads/) 가 없으면 설치 (설치 화면에서 *Add python.exe to PATH* 체크)
2. 저장소를 받은 폴더에서 `analyzer\run_server.bat` 더블클릭
   - 처음 한 번은 라이브러리를 설치합니다 (NVIDIA GPU 가 있으면 GPU 판 PyTorch 포함, 약 5GB · 몇 분)
   - 검은 창에 `배구 영상 인식 서버 http://127.0.0.1:8765` 가 나오면 준비 끝. **이 창을 닫으면 서버가 꺼집니다**
3. 브라우저로 **http://127.0.0.1:8765** 를 열고 **▶ 경기 분석 화면 열기** (= `http://127.0.0.1:8765/app/#analysis`)
   - 이 서버가 사이트 화면도 함께 내주므로, 화면과 서버가 같은 주소라 브라우저 권한 없이 「🤖 AI 영상 인식」이 바로 연결됩니다
   - 공개 사이트(`lodostheory.github.io`)의 분석 탭에서도 **연결 확인**으로 쓸 수 있지만, 브라우저가 공개 사이트의 PC 접근(로컬 네트워크 접근)을 막으면 연결되지 않습니다. 크롬이 허용을 물으면 **허용**, 막혀 있으면 화면에 나오는 「PC 서버 주소에서 분석 화면 열기」 버튼을 쓰세요
   - 두 주소는 브라우저 저장 공간이 따로라, 기록은 **☁ 서버 저장** 으로 옮기면 양쪽에서 불러올 수 있습니다
4. 위 「경기 영상」에 유튜브 주소를 불러온 뒤 순서대로
   1. **영상 받기** — 1080p 이하 최고 화질, 영상만 받음 (소리 없음, ffmpeg 필요 없음)
      - **✂ 앞뒤 잘라 내기**: 남길 시작·끝 시각을 넣고 「자르기」 → 받은 파일에서 필요 없는 앞뒤를 지움(다시 압축하지 않아 몇 초면 끝나고 화질 그대로). 압축 구조상 시작은 1~4초 앞 키프레임에서 잘림. 잘라 낸 뒤에도 화면 · 분석 시각은 유튜브 시각 그대로. 「원본 다시 받기」로 되돌림
   2. **코트 모서리 찍기** — 먼 쪽 왼쪽 → 먼 쪽 오른쪽 → 가까운 쪽 오른쪽 → 가까운 쪽 왼쪽. 화면 밖 모서리는 둘레 여백에 짐작해서. 계산된 **빨간 네트 선**이 실제 네트 아래 바닥과 겹치면 잘 찍은 것
   3. **분석** — 우리 팀 위치(가까운 쪽/먼 쪽), 규격(9인제 21×10.5m / 6인제 18×9m), 초당 분석 장수, 모델, **분석 구간**(시작 · 끝 시각을 `1:30` 처럼 입력하거나 ⏱ 지금 버튼으로 재생 위치를 넣음. 끝을 비우면 영상 끝까지)
   4. **결과 검토** — 후보를 누르면 그 장면을 영상으로 보여 주고 팀·동작을 미리 골라 둡니다. 번호와 평가만 누르면 그 장면 시각으로 기록되고 다음 후보로. 한 번 고른 선수는 그 트랙에 연결되어 다음부터 자동 선택
   - **⬇ 엑셀 리포트**: 트랙별 동작 수 요약 + 전체 이벤트 로그

받은 영상은 `data\videos`, 결과(JSON·엑셀)는 `data\results` 에 쌓입니다. 필요 없으면 지워도 됩니다.

## 속도 (참고)

| PC | 모델 | 1프레임 | 초당 10장 분석 시 |
|---|---|---|---|
| GTX 1650 (4GB) | 보통(s) | 약 0.08초 | 경기 시간과 비슷 (1시간 경기 ≈ 1시간) |
| CPU (i9-10900) | 보통(s) | 약 0.4~0.6초 | 경기 시간의 4~6배 |

CPU 만 있으면 모델 「빠름」, 초당 5장, 구간 나눠 분석을 권장합니다.
GTX 16 시리즈는 FP16(반정밀도)이 결과를 망가뜨려서 항상 FP32 로 계산합니다.

## 명령줄로 쓰기 (서버 없이)

```bat
.venv\Scripts\python volleyball_analyzer.py --video 체육관.mp4                         :: 첫 화면에서 마우스로 코트 모서리 찍기
.venv\Scripts\python volleyball_analyzer.py --video 체육관.mp4 --corners "420,280 1500,280 1780,950 140,950" --court 9 --excel 기록.xlsx
.venv\Scripts\python volleyball_analyzer.py --youtube https://youtu.be/XXXXXXXXXXX --start 60 --end 600 --annotate 확인용.mp4
```

`--annotate` 를 주면 선수 상자 · 트랙 번호 · 공 · 코트 선을 그린 확인용 영상을 만듭니다.

## 정확도를 높이려면

- **카메라**: 엔드라인 뒤 높은 곳(2층 · 삼각대)에 고정, 코트 전체가 보이게. 손으로 들고 찍어 화면이 움직이면 코트 위치가 틀어집니다
- **화질**: 1080p 이상, 가능하면 60fps (공이 작고 빠름). 분석 프레임(초당 장수)을 15~30 으로 올리면 놓치는 터치가 줄어듭니다
- **먼 공 찾기 강화**: 화면을 2×2 로 잘라서 다시 찾음(SAHI 와 같은 원리). 느려지지만 먼 쪽 작은 공을 더 잡습니다
- **배구공 전용 가중치**: `train_ball.py` 로 배구공 데이터셋을 추가 학습하면 `models\volleyball_ball.pt` 가 생기고 서버가 자동으로 씁니다. AI-Hub 「스포츠 영상 데이터(배구)」나 Roboflow Universe 의 volleyball 데이터셋을 YOLO 형식으로 준비하세요
- **트랙 번호 바뀜**: 선수가 겹치면 ByteTrack 번호가 바뀔 수 있습니다. 분석 탭의 「트랙 ↔ 선수 연결」에서 고치거나, 검토하면서 번호를 고르면 그 트랙에 다시 연결됩니다

## 한계

동작 판별은 관절 자세와 공 궤적에 기반한 **규칙**이라, 특히 토스/디그, 블로킹/공격 구분이 틀릴 수 있고 평가(#, +, = …)는 판단하지 않습니다.
그래서 결과를 자동으로 기록하지 않고 **사람이 확인하는 후보**로 보여 줍니다. 본인 또는 권한이 있는 영상만 내려받아 분석하세요 (유튜브 이용약관).

## 서버 API

| 요청 | 설명 |
|---|---|
| `GET /app/...` | 사이트 화면(저장소 맨 위 폴더의 html · js · 아이콘)을 이 서버 주소에서 제공 |
| `GET /health` | 서버 · 장치(GPU) 상태 |
| `POST /videos {url}` | 유튜브 영상 받기 시작 |
| `GET /videos`, `GET /videos/<id>` | 받은 영상 목록 · 진행률 (`videos\` 폴더에 넣은 파일도 목록에 나옴) |
| `GET /videos/<id>/frame?t=초&w=폭` | 그 시각 화면 JPEG |
| `POST /videos/<id>/trim {start, end}` | 받은 영상의 앞뒤 잘라 내기 (유튜브 시각, 무손실) · `POST /videos {url, force:true}` 는 원본 다시 받기 |
| `POST /jobs {video, corners, court, fps, start, end, model, tiles}` | 분석 시작 |
| `GET /jobs/<id>` | 진행률 · 결과(이벤트) |
| `POST /jobs/<id>/cancel` | 취소 |
| `GET /jobs/<id>/excel` | 엑셀 리포트 |
| `POST /jobs/<id>/events/delete {index, t}` | 후보 하나 삭제 (JSON · 엑셀 다시 저장, 분석 탭 후보 옆 ✕) |
| `POST /jobs/clear` | 끝난 분석 결과(JSON · 엑셀) 전체 삭제 · 진행 중인 분석은 남김 (분석 탭 「🗑 결과 전체 삭제」) |

서버는 이 PC 안(127.0.0.1)에서만 열리고, VOLLEYBALL MANIA 사이트와 이 PC 주소에서 온 요청만 받습니다.

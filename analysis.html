📹 경기 영상 유튜브 주소를 넣고 불러오기

🤖 AI 영상 인식 PC 에서 분석 서버를 켜면 영상 속 터치 장면과 선수 위치를 자동으로 찾아 줍니다
이 기능은 PC 에서만 됩니다. 저장소의 analyzer\run_server.bat 를 실행하면(처음 한 번은 설치에 몇 분) 서버가 켜집니다. 자세한 방법은 analyzer 안내. 본인 또는 권한이 있는 영상만 분석하세요.
🖥 PC 서버 주소에서 분석 화면 열기 서버가 켜져 있는데도 연결이 안 되면, 브라우저가 이 공개 사이트의 PC 접근을 막은 것입니다. 이 버튼으로 열면(화면과 서버가 같은 주소) 권한 없이 바로 연결됩니다. 기록은 서버에 저장해 두면 양쪽에서 불러올 수 있습니다.

2. 코트 모서리 찍기

코트 바닥 선의 네 모서리를 ① 먼 쪽 왼쪽 → ② 먼 쪽 오른쪽 → ③ 가까운 쪽 오른쪽 → ④ 가까운 쪽 왼쪽 순서로 누르세요. 모서리가 화면 밖이면 둘레의 빗금 여백에 짐작해서 찍으면 됩니다. 4개를 찍으면 계산된 네트 위치(빨간 선)가 그려지니, 실제 네트 바로 아래 바닥과 겹치는지 확인하세요. 카메라는 엔드라인 뒤 높은 곳에 고정된 영상이 가장 정확합니다.

4. 결과 검토

후보를 누르면 그 장면을 영상으로 보여 주고, 패드에 AI 가 추정한 팀·동작을 미리 골라 둡니다. 선수 번호와 평가만 누르면(또는 코드 입력) 그 장면 시각으로 기록되고 다음 후보로 넘어갑니다. 한 번 고른 선수는 그 트랙에 연결되어 다음부터 자동으로 골라집니다.
트랙 ↔ 선수 연결 (AI 의 트랙 번호 T 를 실제 선수에 연결)

코드 입력 방법 · 단축키
코드 = [팀] 등번호 동작 [평가] [구역]   예) 7S+ 우리 7번 서브 좋음 · a12A# 상대 12번 공격 득점
팀: 없음(또는 *) = 우리 팀, a = 상대 팀 · 등번호는 선수 명단의 번호
동작: S 서브 · R 리시브 · E 토스 · A 공격 · B 블로킹 · D 디그(수비) · F 프리볼 (대소문자 상관없음)
평가: # 완벽·득점 · + 좋음 · ! 보통 · - 나쁨 · / 공격 차단당함·리시브 바로 넘어감 · = 범실 (생략하면 +)
구역(선택): 서브·공격 뒤 숫자 1개 = 떨어진 구역, 2개 = 출발·도착 구역 → 보드에 화살표 자동 (예: a5A#46). 리시브·디그 뒤 숫자 = 받은 구역. 구역 번호는 각 팀 기준으로 네트 앞 왼쪽부터 1~9 (보드의 작은 숫자). 숫자를 안 붙이고 입력한 뒤 코트를 탭해도 방향이 기록됩니다
득점 자동 판정: S# A# B# = 그 팀 득점, = 범실 = 상대 득점, A/ = 상대(블로킹) 득점 → 랠리가 끝나고 다음 랠리로
짝 코드: 득점 직후 상대 쪽 짝 동작(S#↔R=, A#↔D=·B=, A/↔B#)을 넣으면 새 점수가 아니라 방금 랠리에 붙습니다 (예: 7A# a3D=)
점수만: p = 우리 득점, ap = 상대 득점 (네트 터치 등 동작 없이)
키: Enter·Space 입력 · 빈 칸에서 Space 영상 재생/정지 · [ ] 2초 뒤/앞 · { } 10초 · \ 느리게 · 빈 칸에서 Backspace 마지막 입력 되돌리기 · Esc 지우기 · 페이지 어디서든 글자를 치면 입력창으로
여러 코드를 띄어 쓰고 한 번에 넣어도 됩니다 (7S+ a12R- a5E a9A#). 한글 입력 상태로 쳐도 자동으로 바뀝니다 (ㄴ → S).
